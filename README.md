# AI for Java Developers: Zero to Hero 🚀

An interactive, enterprise-grade educational platform designed specifically for Java Developers to master Generative AI concepts — from foundational tokens to 15+ YOE Principal Architect system designs.

## Features
- **Zero Framework**: 100% Vanilla HTML5, CSS3, and modern ES6 JavaScript.
- **GitHub Pages Ready**: Zero build steps. Push to your repository and enable GitHub Pages on `main` branch.
- **Java Developer First**: Maps every GenAI concept to familiar Java/Spring paradigms (e.g., GC vs Context Window, HashCode vs Vectors, Reflection vs Tool Calling).
- **Interactive SVG Architecture Diagrams**: Visual deep-dives into RAG, Transformers, Tool Calling, and Agentic Workflows.
- **20 Real-World Java Examples Per Topic**: Production-ready code snippets using Spring AI, LangChain4j, and standard Java.
- **0 to 15+ YOE Interview Guide**: Rigorous interview prep tailored across Junior, Mid, Senior, Lead, and Principal Architect tiers.
- **100-Question Mastery Quiz**: Full-featured quiz engine with instant evaluation, filters, timers, and detailed explanations.
- **Memorization Hub & Flashcards**: Quick mnemonics, formula cards, and the Java-to-AI Rosetta Stone.

## Deploying to GitHub Pages
1. Push this repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of AI for Java Developers Platform"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. In your GitHub repository, go to **Settings** > **Pages**.
3. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
4. Select `main` branch and `/ (root)` folder, then click **Save**.
5. Your website will be live at `https://<your-username>.github.io/<your-repo-name>/` in ~60 seconds!
